# Frontend - Asistencia Panadería

Estructura inicial del frontend para el sistema de control de asistencia de la panadería.

## Archivos principales

- `public/index.html`: página principal con plantilla Bootstrap.
- `src/css/styles.css`: estilos personalizados.
- `src/js/app.js`: scripts de interacción.
- `src/assets/images/`: recursos gráficos futuros.

## Uso

1. Instalar dependencias:

```bash
cd frontend
npm install
```

2. Iniciar servidor de desarrollo:

```bash
npm start
```

> El sitio se sirve desde `public/index.html`.
